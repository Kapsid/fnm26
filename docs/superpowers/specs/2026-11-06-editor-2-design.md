# Database Editor 2 — Design

Date: 2026-11-06. This is the owner's playtest feedback on the 1.1.0 editor (`docs/superpowers/specs/2026-11-04-database-editor-design.md`), confirmed point by point ("yes, all good"). Items marked *(builder's call)* were decided by Claude.

## Intent

The first editor lets a player rename things and re-rate the core squads. After playing with it, the owner wants three more things:
- deeper control over players: raw attributes, traits, the wider pool, clubs anywhere;
- the ability to add to the world's lists instead of only renaming them;
- names that can differ per language, edited inside the editor without switching the whole game's language.

## The owner's feedback, as agreed

1. **Deleting players is easy to find.** Swipe-to-delete exists today but nobody finds it. Add a Delete action on the player screen, with an Undo snackbar, keeping the swipe.
2. **The wider player pool is editable.** Each nation's day-one pool can be edited in the database, not only the core squad. The pool is the fringe players the game creates today (ids from `PoolGenerator.firstFringeId`).
   - The squad screen gets **Squad** and **Pool** tabs.
   - Pool players have the same fields as squad players and can be added, edited and deleted.
   - A database that leaves a nation's pool untouched keeps today's generated pool. *(builder's call)*
   - Future youth intakes stay generated by the game, as now. The database fixes only who exists on day one. *(builder's call)*
3. **Names per language.** A custom name (competition, nation, club, stadium, sponsor, Y account, press) can have a different value per language.
   - A name with only one value shows that value in every language, which is today's behaviour.
   - A name with values for some languages shows the matching one, and falls back to the database's main value for the others.
4. **Adding, not just renaming.**
   - **Sponsors:** add new sponsor brands.
   - **Clubs:** add new clubs to a country's league. This reverses an earlier decision, so the added clubs need a tier: the editor asks for one, and the transfer clock (`ClubService`) uses it. Removing the game's own clubs stays off.
   - **Y accounts:** add new named accounts, with a chosen persona (fan, pundit, journalist, meme), so they post in a voice the game already has.
5. **Raw attributes and traits.**
   - The player screen keeps Overall + type as the quick way. An **Advanced** section shows the three stored qualities (physical, technical, stamina) as sliders, with the resulting Overall shown live. This was option C of the original design.
   - **Traits** (superseded by "Decisions after the builder check": the game's existing traits are used instead). The originally proposed set:
     - Penalty specialist: preferred penalty and shootout taker, with a skill bonus.
     - Free-kick specialist: preferred direct free-kick and dead-ball taker.
     - Long throw: the side gains the long-throw style when he plays.
     - Aerial threat: preferred target for set-piece headers.
     - Captain: preferred captain.
   - Each trait's effect must stay within today's balance bands. These are display-and-selection preferences that use existing engine levers, not new strength.
6. **Language switch inside the editor.** The editor has its own language picker. It shows and edits the per-language names (item 3) for the chosen language, without changing the game's language.
7. **Clubs from any country.** The player's club picker searches every club in the world, not only his nation's league. Clubs from other countries are listed under their country.
8. **National teams are not editable.** Nation names and codes don't need editing. The Nations section is removed from the editor.
   - **Builder's call:** existing databases that already renamed a nation keep working. Their renames still apply in careers and in New Game, but the editor no longer offers the section.
   - This is an owner decision to simplify; it is not a fix.

## Decisions after the builder check (2026-11-06; builder's calls unless marked)

- **Traits are the game's existing traits.** These are `PlayerTraits.of`: setPiece, leader, hothead, bigGame, wasteful, and the rest. The five invented traits in item 5 are dropped.
  - For each player, the creator either leaves traits on **Random** (today's behaviour: rolled per save, at most 2) or picks up to 2 traits.
  - Picked traits replace the roll and are the same in every career on that database.
  - Traits act exactly as they do today, including in the background simulator. There is no new engine behaviour and no new strength.
  - The manager's own choices (takers, captain, throw-in style) still come first, as they do now.
- **Added clubs join their country's league at that league's tier.** No per-club tier is asked.
  - Countries with a written league list get the club added to that list.
  - Countries without one (built from city names) keep their city clubs. Added clubs join them, so players spread across all of them and don't pile into the one added club.
  - Clubs can be added to any country.
- **Added Y accounts.**
  - The creator picks one of the game's account types: fan, pundit, meme, stats, rival, ex-pro or neutral. The temperament is derived the way it is today.
  - The creator also picks where the account appears: a chosen nation's feed, or every nation's.
- **Added sponsors.**
  - The creator picks a deal type from the five existing ones and an industry from the existing list.
  - The description is optional. Without one, the game uses its existing line for that deal type.
  - Added sponsors are offered in the sponsor round like the built-in brands.
- **Editing a pool fixes that nation's whole pool.**
  - Opening a nation's Pool tab shows today's generated pool. The first edit fixes the whole pool exactly as shown: names, ratings and clubs.
  - Untouched pools stay generated per career with their default-world strength, as in 1.1.0. They are never rebuilt from an edited squad, so 1.1.0 careers don't change.

## Non-goals

- Editing youth intakes after day one.
- Removing the game's built-in clubs, sponsors or Y accounts.
- New match-engine strength from traits.
- Photos (unchanged: trophies only).

## Constraints

- Everything from the 1.1.0 spec still holds: default careers are untouched, files are data only, imports are validated, every string is in 28 languages, and there are no em dashes or "World Cup" in English copy.
- The `.fnmdb` format version goes up to 2, with a migration from 1. 1.1.0 files keep importing.
- A career that started on a 1.1.0 database keeps working unchanged.
- Added clubs, sponsors and accounts must have ids that never collide with the game's own lists in later updates (an id range reserved for packs).
- The work happens on its own branch while the 2D view continues on `feature/pitch-view`. Test runs take turns on the Mac.

## Left to the builder

- How the per-language names are stored and shown.
- The tier choices for added clubs.
- The trait effect sizes, within the balance bands.
- How the pool tab pages a large pool.
- The editor language picker's placement.
