# Fix Batch 2026-08-20 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land twenty-four playtest fixes (a–x) — text that is never cut, a manager section that makes sense, a youth pyramid that fills from the bottom, a forced press conference, transfers with realistic money, and a dozen smaller corrections.

**Architecture:** Mechanical fixes first, then the shared `WholeText` widget and its call sites, then one combined schema bump carrying staff identity and call-up windows, then the domain reworks (youth, press, board, transfers), then a measured — not guessed — nudge to world-sim variance. Every domain change is a pure function with a unit test; every UI change is a widget test or a device check.

**Tech Stack:** Flutter, Riverpod (no codegen — see project memory), Drift + build_runner `--force-jit`, `gen_l10n` (EN + CS).

**Spec:** `docs/superpowers/specs/2026-08-20-fix-batch-design.md`

## Global Constraints

- **No `@riverpod` codegen.** Hand-written providers only — the annotation conflicts with `drift_dev`.
- **Codegen command:** `dart run build_runner build --delete-conflicting-outputs --force-jit`.
- **Schema bumps preserve saves.** Stepwise migration from the current version; add a step, never rewrite the ladder. Regenerate `schema_versions.dart`.
- **Every user-visible string is localised** in `lib/l10n/app_en.arb` AND `lib/l10n/app_cs.arb`, with an `@key` description in EN.
- **`flutter analyze` must be clean** before any commit.
- **Both simulators are calibrated together.** `MatchEngine` is NOT touched in this batch; only `RatingMatchSimulator`, and only if the measurement in Task 14 justifies it.
- Commit after each task.
