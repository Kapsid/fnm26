Football Nations Manager

代表チームを率いて、サッカーの頂点へ。

オフラインで遊べる

すべての試合はスマートフォン上で進みます。アカウントもネット接続も不要。セーブは後から別のスマートフォンやタブレットに移せます。

209の国と地域

スペインか、ジンバブエか。挑戦も悩みもまったく違います。サイクルの合間に別の国へ移ることもできます。

終わりのないサイクル

予選、大陸選手権、世界選手権、そしてまた最初から。抽選、開催国の選考など、代表サッカーのすべてがここにあります。

国内スタジアム

スタジアムを地図で確認し、改修したり新しく建てたり。大きなスタジアムは収入を生み、大会招致の力にもなります。

大会を招致する

欧州選手権(または自分の大陸の選手権)や世界選手権の開催に立候補し、大会を自国に呼び込みましょう。

年間最優秀選手

毎年12月、世界が投票します。授賞式の壇上に、あなたの選手は立てるでしょうか。

28言語に対応

28の言語でプレイできます。新たに日本語、韓国語、ヒンディー語、タイ語、マレー語、ルーマニア語にも対応しました。

ライブで観る試合

フォーメーションを変え、選手を交代し、ハーフタイムに士気を高める。あるいは閉じてしまってもかまいません。ただしCsaplárの罠にはご注意を!

2Dで観る試合

すべての試合を2D TVモードでライブ観戦。スタンドの向こうにはその街ならではのスカイラインが見えます。ゴールやカードのバナー、セットプレー、一本ずつ蹴り合うPK戦も。

天候

雨、雪、霧、もや、澄んだ夜、雷雨、そして砂嵐。天候もピッチの上で試合を彩ります。

エディター

選手、クラブ、スタジアム、大会、監督、スポンサー、メディア、そしてYまで編集できます。データベースを書き出して友達や私たちのDiscordで共有し、友達のデータベースでキャリアを始めることも。

PKは自分の手で

蹴る順番を決めるのも、実際に蹴るのもあなたです。

ユースピラミッド

U-13からU-21まで。若い選手を最初から見守れます(ユース代表は今後追加予定)。

選手を細かく把握

負荷と移籍に目を配りましょう。すべてが士気とコンディションに影響します。

記者が問い、世界が反応する

要注意。不用意な答えはプレッシャーを生みます。そしてYのフィードでは容赦なく叩かれます!

あなただけのキャリア

監督としての評価を高め、協会全体の予算と方針を決め、目標を達成しましょう。

協会の評価がすべて

協会の機嫌がすべてです。小さな失敗なら許されても、大きな失敗の後は荷物をまとめることに。そのとき届く唯一のオファーは、アンドラからかもしれません。

残り続ける記録

国ごと、大会ごとの歴代得点王など、記録は数え切れません。周りの世界は動き続けます。置いていかれないように!

支払いは一度だけ

サブスクリプションも、広告も、ゲーム内通貨も一切ありません。

1サイクルまるごと無料

制限なしで1サイクルまるごと無料で遊べます。1、2時間もあれば、自分に合うかどうかわかるはずです。

長く遊べるように

2026年春から開発を続けていて、ユース代表、チャレンジなど、まだまだ追加予定です。気に入ったら、フル版を購入してプロジェクトを応援してください。
