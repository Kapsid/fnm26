# Screenshots for the landing page

Drop files here named `shot-1.jpg` … `shot-5.jpg` and the gallery on the
landing page shows itself. Leave it empty and the whole section stays hidden,
rather than printing a row of broken-image icons.

They are the same shots the App Store listing wants, so take them once:

1. a match in progress
2. the tactics pitch
3. the squad
4. a tournament bracket or the draw
5. the world ranking

Take them on a real device rather than the simulator, with a save that has
real data in it. Empty states sell nothing.

Any width works here; the page scales them. The App Store is the fussy one,
and wants exact dimensions.
