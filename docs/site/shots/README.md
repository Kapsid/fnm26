# Images the landing page is waiting for

## Screenshots: `shot-1.jpg` … `shot-5.jpg`

Drop them in this folder and the carousel shows itself. Leave it empty and the
whole section stays hidden rather than printing broken-image icons.

These are the same shots the App Store listing wants, so take them once:

1. a match in progress
2. the tactics pitch
3. the squad
4. a tournament bracket or the draw
5. the world ranking

Take them on a real device, from a save with real data in it. Empty states
sell nothing. Any width works here; the page scales them.

## Your photo: `../me.jpg`

One level up, beside `index.html`. It is cropped to 4:5 portrait, so a shot
with some room above and below your head survives the crop. Without it the
About section simply drops the picture and keeps the text.
