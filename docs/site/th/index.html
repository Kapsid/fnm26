คุมทีมชาติสักทีม แล้วพาขึ้นสู่จุดสูงสุดของวงการลูกหนัง

เล่นแบบออฟไลน์

ทุกนัดทำงานบนโทรศัพท์ของคุณ ไม่ต้องมีบัญชี ไม่ต้องต่ออินเทอร์เน็ต และย้ายเซฟไปยังโทรศัพท์หรือแท็บเล็ตเครื่องอื่นได้ในภายหลัง

209 ทีมชาติ

สเปนหรือซิมบับเว? ความท้าทายต่างกัน ปัญหาก็ต่างกัน และคุณยังเปลี่ยนไปคุมทีมชาติอื่นได้ระหว่างรอบ

วงจรที่ไม่มีวันจบ

รอบคัดเลือก รายการชิงแชมป์ทวีปของคุณ ชิงแชมป์โลก แล้ว... ก็เริ่มใหม่ การจับสลาก การเลือกเจ้าภาพ และทุกอย่างที่ฟุตบอลทีมชาติมี

สนามกีฬาแห่งชาติ

ดูสนามของคุณบนแผนที่ อัปเกรด หรือสร้างสนามใหม่ สนามที่ใหญ่ขึ้นทำเงินได้มากขึ้น และช่วยได้เมื่อคุณยื่นเสนอตัวเป็นเจ้าภาพ

เป็นเจ้าภาพการแข่งขัน

ยื่นเสนอตัวเป็นเจ้าภาพชิงแชมป์ยุโรป (หรือรายการของทวีปคุณเอง) หรือชิงแชมป์โลก แล้วพาทัวร์นาเมนต์มาจัดที่บ้าน

นักเตะยอดเยี่ยมประจำปี

ทุกเดือนธันวาคมทั้งโลกร่วมโหวต นักเตะของคุณจะได้ขึ้นเวทีในพิธีมอบรางวัลหรือไม่?

28 ภาษา

เกมนี้รองรับ 28 ภาษา ตอนนี้มีภาษาญี่ปุ่น เกาหลี ฮินดี ไทย มลายู และโรมาเนียด้วย

แมตช์สด

เปลี่ยนแผน เปลี่ยนตัว ปลุกขวัญกำลังใจช่วงพักครึ่ง หรือจะปิดไปเลยก็ได้... แต่ระวังกับดัก Csaplár ไว้ให้ดี!

การแข่งขันแบบ 2D

ติดตามทุกนัดแบบสดในโหมด 2D TV ในสนามที่มีเส้นขอบฟ้าอันโด่งดังของเมืองอยู่หลังอัฒจันทร์ พร้อมแบนเนอร์เมื่อเกิดประตูและใบเหลืองใบแดง ลูกตั้งเตะ และการดวลจุดโทษทีละลูก

สภาพอากาศ

ฝน หิมะ หมอก หมอกควัน คืนฟ้าใส พายุฝนฟ้าคะนอง หรือพายุฝุ่น สภาพอากาศก็ร่วมเล่นด้วยบนสนาม

ตัวแก้ไข

แก้ไขผู้เล่น สโมสร สนาม รายการแข่งขัน ผู้จัดการทีม สปอนเซอร์ สื่อมวลชน และ Y ส่งออกฐานข้อมูลของคุณ แบ่งปันให้เพื่อนหรือใน Discord ของเรา แล้วเริ่มอาชีพบนฐานข้อมูลของเพื่อน

ยิงจุดโทษด้วยมือคุณเอง

คุณเลือกลำดับผู้ยิง และคุณเป็นคนยิงเอง

พีระมิดเยาวชน

ตั้งแต่ U-13 ถึง U-21 ติดตามเด็กๆ ได้ตั้งแต่เริ่มต้น (ทีมชาติชุดเยาวชนจะตามมาภายหลัง)

ข้อมูลนักเตะแบบละเอียด

คอยดูภาระงานและการย้ายทีม ทุกอย่างส่งผลต่อขวัญกำลังใจและความฟิต

สื่อถาม โลกตอบสนอง

ระวังให้ดี คำตอบที่ไม่ยั้งคิดจะสร้างแรงกดดัน และบนฟีด Y พวกเขาจะรุมถล่มคุณ!

อาชีพของคุณเอง

สร้างโปรไฟล์ของคุณ กำหนดงบประมาณและทิศทางของทั้งสมาคม และทำเป้าหมายให้สำเร็จ

บอร์ดที่คุณต้องรับผิดชอบ

อารมณ์ของบอร์ดคือทุกอย่าง ความล้มเหลวเล็กๆ อาจได้รับการให้อภัย แต่หลังความล้มเหลวครั้งใหญ่คุณต้องเก็บกระเป๋า และข้อเสนอเดียวที่เหลืออาจมาจากอันดอร์รา

สถิติที่คงอยู่

ดาวซัลโวตลอดกาลของทุกทีมชาติ ทุกรายการ และอีกมากมาย โลกรอบตัวคุณยังคงเดินต่อไป และคุณต้องตามให้ทัน!

จ่ายครั้งเดียว

ไม่มีการสมัครสมาชิก ไม่มีโฆษณา ไม่มีสกุลเงินในเกม ตลอดไป

เล่นฟรีหนึ่งรอบเต็ม

เล่นฟรีหนึ่งรอบเต็มโดยไม่มีอะไรถูกกั๊กไว้ แค่ชั่วโมงหรือสองชั่วโมง คุณก็จะรู้ว่าเกมนี้เหมาะกับคุณหรือไม่

สร้างมาเพื่อเล่นยาว

พัฒนามาตั้งแต่ฤดูใบไม้ผลิปี 2026 และยังมีอีกมากที่กำลังจะมา ทั้งทีมชาติชุดเยาวชน และชาเลนจ์ ถ้าคุณชอบ ช่วยสนับสนุนโปรเจกต์ด้วยการซื้อเวอร์ชันเต็ม
